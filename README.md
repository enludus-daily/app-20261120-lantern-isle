# 灯り島：昼は島づくり、夜は生きのびる / Lantern Isle: Craft & Survive

**昼はのんびり島暮らし、夜は 3 分のサバイバー。** 浜で拾った貝・流木・花・石で灯台やランタンを作ると、それがそのまま夜の武器・明かり・仲間になる。夜にもやを払って集めた「光る砂」で、昼の島をもっと強く、もっと素敵にする。

- 題材（idea-fusion：エンタメ × エンタメ）：自動で戦うサバイバー × 島暮らし（監督の指示 daily-ideas #39、今日の記録 #40）
- だれの：寝る前や休憩に「育てる遊び」と「手に汗をにぎる数分」の両方がほしい人。のんびり系は手応えが薄く、サバイバー系は積み上げが数字の強化だけで愛着がわかない
- 端末の中だけ（ログイン・サーバー・広告・解析なし）。Apple Intelligence は使わない

## 遊び方

1. **昼**：浜できらりと光る拾い物をタップ（毎日の潮で 10 か所が変わり、「潮の恵み」の素材は 1 つ多い）
2. **作る**：材料で 12 の作り物（Pro で 18）を島に置く。レベル 3 まで。レベル 2 からは夜の「光る砂」が要る
3. **住人**：小さな生き物の頼みごとをかなえると引っ越してきて、夜は仲間としてついてくる（5 人、Pro で 8 人。1 人 3 つの頼みごと）
4. **夜へ**：3 分。画面のどこかに指を置いて動かすと歩く（片手）。攻撃は自動。砂を集めるとレベルアップ（時間が止まり、3 枚から 1 枚選ぶ）。2 分 30 秒に大もや
5. **夜明け**：生きのびたら次の夜へ（夜ごとに少しずつ手強くなる）。途中で「昼にもどる」でも、集めた砂は持ち帰れる

### 昼と夜の因果（作り物 → 夜の力）

| 作り物 | 夜の力 |
|---|---|
| たき火（最初からある） | 近くのもやを焼き、そばにいると体力が戻る |
| 灯台 | 見える範囲が広がり、回る光がもやを払う |
| 貝の風鈴 | 近いもやへ貝のつぶてを投げる |
| 流木の柵 | たき火のまわりの柵がもやを押し返す |
| 花のランタン | 光の玉が自分のまわりを回る |
| ハンモック / 石の小道 / 花だん | 体力 / 速さ / 回復 |
| 潮だまり | 水に入ったもやが遅くなる |
| 見張り台 | 遠くのもやを矢で射る |
| 風車 | 光る砂を遠くから引き寄せる |
| 浜の鐘 | ときどき鳴って、まわりのもやを吹き飛ばす |
| Pro：星の望遠鏡・ほら貝の大砲・ホタルのびん・灯りの小舟・雪あかり・祭りのやぐら | 星を落とす・貫く大砲・追いかけるホタル・島を回る舟・凍えさせる・すべての攻撃と砂 +10% |

### 作らなかったもの

オンラインのランキング・ガチャ・消耗型の課金（ジェム）・広告・ログイン・SpriteKit（Canvas と TimelineView で描く）・Apple Intelligence。

## 世界観と見た目

- **このアプリでは〔島の地図と灯台の明かり〕が〔主役の Canvas の島〕になる。** 島の形・作り物・住人・自分・もやはすべて自作の Canvas（`App/Sources/Views/Art.swift`）。画像や SF Symbols に置き換えていない
- **昼と夜で同じ島がまるで違って見える**：昼は真上から少し斜めに見た島（砂浜の白 `#F8EFDF`、サンゴ `#F5876F`、ターコイズの海 `#5CCBC6`、草 `#A8D38E`）。夜は同じ島の形を真上から、深い紫（`#160D2B`・島 `#2D2050`）のもやの中で、作った物と自分のランタンだけが琥珀色（`#FFC872`）に光る（灯りの外は闇の層で隠す）
- 書体は丸ゴシック（`.rounded`）の heavy の題字と medium の本文。前日までの「明朝・細い線・淡い 1 色」（11/09〜15）、洋館の夜（11/19 カギことば）、池の青緑（11/18 うおさがし）と、色の系統・地の明るさ・書体・主役の形の 4 つが違う
- ボタンは「島の地面」：下辺に厚み（4pt）があり、押すと沈む（`ChunkyButtonStyle`）
- トークンは `App/Sources/Views/Theme.swift`（昼 `Day`・夜 `Night`・`Fonts`・`Radius`）。色に意味の段階：素材ごとの色、体力が 30% を切ると赤い縁、レベル 1〜3 の点、潮の恵みの素材はサンゴの地
- 画面はライトに固定（昼も夜も自前の色で描くため。夜の暗さはダークモードではなく世界の時間）

### 参考にしたアプリと借りたもの（ui-reference）

1. 自動で戦うサバイバー系（Vampire Survivors など）：夜の「スティックは画面のどこでも」と、時間を止めて 3 枚から選ぶレベルアップの幕
2. Finch：丸いキャラが画面の中心にいて、頼みごとを吹き出しで出す（昼の島の住人）
3. 島づくりのゲーム全般：真上から少し斜めの小さな島に、作った物がその場に増えていく

キャラ・絵・名前はすべてオリジナル（ヤシガニの「ハサミ」、ツノメドリの「ポポ」など）。

## 手応えの表

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | ボタンが沈む（下辺の厚みが消える）・0.92 倍 | selection | 木のコツッ（0.4） |
| 1 つ成功（拾う） | きらりが 1.6 倍に広がって消える | impact light | 貝のからん／潮の恵みは 2 音（0.6〜0.8） |

| 失敗・間違い | 足りない：材料の数がサンゴ色／夜の被弾：画面が揺れ、体力 30% 以下で赤い縁 | warning / impact medium | 低いぽすっ／低い音 |

| 完了 | 夜明け：題字が 0.6→1 のバネで出る、朝日の空 | success | 夜明けの和音 |

## 毎日開く理由

1. **毎日の潮**：浜の拾い物 10 か所と「潮の恵み」が毎日変わる（日付から決まる）
2. **住人の頼みごと**：昼の画面の下に、かなえられる頼みごとが出る。かなえると夜の仲間が増える・強くなる
3. **夜の積み上げ**：第 N 夜（夜ごとに手強くなる）、連続の日、いちばん長い夜、夜ごとの棒グラフ（夜の記録）

中身の量：作り物 18 × レベル 3、住人 8 × 頼みごと 3、レベルアップの札 9 種、もや 4 種、夜は段階的に手強くなる。1 日に拾える材料は約 20 なので、全部を作り終えるには数週間かかる。

## 課金

**形：買い切りの Pro ¥480（非消耗型・家族共有）。** 続けて増える中身（毎月の新しいお題など）はないので、サブスクにしない。

- 無料：作り物 12・住人 5・毎日の潮・夜（第 1〜∞ 夜）。核はずっと無料で遊べる
- Pro：作り物 +6（どれも夜の新しい攻撃）・住人 +3（夜の仲間）・終わらない夜（エンドレス）
- 課金の画面は、**最初の夜明けを見て昼にもどったとき一度だけ**出る。あとは設定と、Pro の作り物・住人・終わらない夜を押したときだけ。購入を復元できる。値段は StoreKit の `displayPrice` を出す

## デモで見せる流れ（起動引数 `-demo`、約 18 秒）

1. 昼の島で浜の拾い物を 3 つ拾う（貝のからん）
2. 作るの一覧から見張り台を作る → 島に物が増える
3. 夜へ：同じ島が紫のもやに沈み、灯りの中で自動で戦い、夜明け

## 開発

- `App/Sources/Model/`：素材・作り物・住人・潮（`Content.swift`）、保存と昼のルール（`Island.swift`）、夜のシミュレーション（`NightSim.swift`。決まった刻みで進める値の型、テストできる）
- `App/Sources/AppModel.swift`：画面の状態。保存は拾う・作る・届ける・夜の終わりの区切りでだけ（毎秒は保存しない）
- 画面の言葉は `tr("日本語", "English")`。`python3 scripts/gen-strings.py` で `Localizable.xcstrings` を作る（`--check` で確かめる）
- アイコン：`scripts/make-icon-isle.py`
- 撮影：起動引数 `-screenshotScene <名前>`（`_ja` を付けると日本語）。`day` `craft` `residents` `built` `night` `levelup` `shade` `pro` `result` `fail` `records` `empty` `settings` `paywall` `onboarding`
- UI テスト：`-uiTestFresh` で最初から。主なボタンは `main.` の印
